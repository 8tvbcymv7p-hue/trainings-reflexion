Daten exportieren / importieren

Die Daten werden im Browser gespeichert (geräte-lokal). Mit Export/Import kannst du sie sichern oder zwischen Geräten austauschen.

Hinweise zum Einsatz

  1. Diese App kann auf einem Tablet nach dem Training rumgehen — jeder Spieler wählt seinen Namen.
  2. Alternativ: jeder Spieler ruft die Seite auf seinem Handy auf und nutzt sie individuell.
  3. Daten liegen lokal im Browser — also auf dem Gerät, auf dem reflektiert wird. Für eine Mehr-Geräte-Lösung exportiere die JSON-Daten regelmäßig und konsolidiere sie auf einem Trainer-Gerät.
  4. Sobald wir wissen, dass dir das Konzept gefällt, können wir das auf eine echte Web-App mit Datenbank, Mehrbenutzer-Login und Push-Benachrichtigung umstellen (oder auf Google Forms anbinden).
